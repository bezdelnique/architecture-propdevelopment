Взаимодействие мобильного приложения и API tenant-core-app
- Данные передаются по защищенному протоколу HTTPS через файрволл
- Все запросы кроме запроса на идентификацию должны быть авторизованы 
- Для аутентификации и авторизации используется OAuth 2.0 логин\пароль + двухфакторная авторизация

Взаимодействие приложения tenant-core-app и API партнеров Интеллектуальный домофон и Интелектуальный шлакбаум
- Данные передаются по защищенному протоколу HTTPS
- Все запросы кроме запроса на идентификацию должны быть авторизованы
- Для аутентификации и авторизации используется client_id + client_secret
- Запросы не содержат персональные данные

Взаимодействие API отражено на схеме C4. 
Бэкенд мобильного приложения tenant-core-app реализует контроллеры которые взаимодействуют с системами партнеров.
